title: Several databases
description: Use one context per database, and route requests to a database per tenant.
---

This page is for databases that hold different data. For read replicas of a single database, see [read replicas](/transactions/connections#read-replicas).

## Use one context per database

Declare a context for each. Each has its own models, migrations and `cmd/migrate`, and its own connection pool.

```go keep-db
type Invoice struct {
	ID int64
}

// spot-start
type MainDB struct {
	ant.Context
	Users ant.Table[User]
}

type BillingDB struct {
	ant.Context
	Invoices ant.Table[Invoice]
}
// spot-end
```

A relation can't cross databases. Keep the key, and load the other side in a second query. Mark such a relation `.NoForeignKey()`.

The two contexts can use different databases. `Open` each with its own dialect and DSN:

```go
mainDB, err := ant.Open[MainDB](ctx, postgres.Dialect, "postgres://localhost/main")
billingDB, err := ant.Open[BillingDB](ctx, mysql.Dialect, "app:app@tcp(localhost:3306)/billing?parseTime=true")
```

## Route requests to a database per tenant

To give each large tenant a database of its own, keep a map of open contexts and pick one per request. Open each one once: an ant context owns a connection pool.

Hand each request its own session. A context tracks the entities it loads, and a tracking context serves one operation at a time, so two requests sharing one get `ErrConcurrentUse`. `ant.Session` shares the pool and gives the request a tracker of its own.

```go
type Router struct {
	mu  sync.RWMutex
	dbs map[string]*AppDB
}

func (r *Router) For(ctx context.Context, tenant string) (*AppDB, error) {
	shared, err := r.pool(ctx, tenant)
	if err != nil {
		return nil, err
	}

	// spot-next-line
	return ant.Session(shared), nil
}

// spot-start
func (r *Router) pool(ctx context.Context, tenant string) (*AppDB, error) {
	r.mu.RLock()
	db := r.dbs[tenant]
	r.mu.RUnlock()

	if db != nil {
		return db, nil
	}

	r.mu.Lock()
	defer r.mu.Unlock()

	if db := r.dbs[tenant]; db != nil {
		return db, nil
	}

	db, err := ant.Open[AppDB](ctx, postgres.Dialect, dsnFor(tenant))
	if err != nil {
		return nil, err
	}

	r.dbs[tenant] = db

	return db, nil
}
// spot-end

func dsnFor(tenant string) string {
	return "postgres://localhost/" + tenant
}
```

Close the pools when the process stops:

```go
func (r *Router) Close() error {
	r.mu.Lock()
	defer r.mu.Unlock()

	var errs []error

	for _, db := range r.dbs {
		errs = append(errs, db.Close())
	}

	return errors.Join(errs...)
}
```

Apply migrations to each with `migrate.Up`, which is safe to call from several processes at once.

:::warning[No cross-database transactions]

A transaction can't span databases, and ant has no two-phase commit. Use an outbox to carry a change from one to the other.

:::

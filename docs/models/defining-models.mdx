A model is a Go struct with no base type, tags or generated code. Exported fields are columns. List the model in your database struct to register it.

## A model

```go
// spot-start
type Article struct {
	ID    int64
	Title string
	Views int
}
// spot-end

type BlogDB struct {
	ant.Context
	Articles ant.Table[Article]
}

var Articles = ant.Fields[Article]()
```

This maps to the table `articles`, with `id` as a database-generated primary key. `Open` fails at startup if a model can't be mapped. See [keys](/models/keys) for other primary keys.

## Add IDs and timestamps with ant.Base

`ant.Base` holds `ID`, `CreatedAt` and `UpdatedAt`.

```go
type Article struct {
	// spot-next-line
	ant.Base
	Title string
}

article := &Article{Title: "Hello"}

err := db.Articles.Insert(ctx, article)
// INSERT INTO "articles" ("created_at", "updated_at", "title") VALUES ($1, $2, $3) RETURNING "id"

// spot-next-line
fmt.Println(article.ID, article.CreatedAt, article.UpdatedAt) // all filled in
```

Any model with a `time.Time` field named `CreatedAt` or `UpdatedAt` gets the same [timestamps](/lifecycle/timestamps).

### In JSON {#base-json}

`ant.Base` encodes with camelCase keys: `id`, `createdAt` and `updatedAt`. A model's own fields keep Go's names unless you tag them, so tag them to match:

```go
type Note struct {
	ant.Base
	Title string `json:"title"`
	Body  string `json:"body"`
}

out, err := json.Marshal(note)
// {"id":1,"createdAt":"2026-11-01T09:00:00Z","updatedAt":"2026-11-01T09:00:00Z","title":"Hello","body":"..."}
```

Before v0.6.0 the keys were `ID`, `CreatedAt` and `UpdatedAt`. Decoding ignores case, so a body or a stored document with the old keys still reads. To keep sending the old keys, or to send others, such as `created_at`, embed a base of your own in place of `ant.Base`. A field named `ID` is the key and `CreatedAt` and `UpdatedAt` are stamped by convention, so it works the same:

```go
type Base struct {
	// spot-start
	ID        int64     `json:"ID"`
	CreatedAt time.Time `json:"CreatedAt"`
	UpdatedAt time.Time `json:"UpdatedAt"`
	// spot-end
}

type Invoice struct {
	Base
	Total int64
}
```

A response type per endpoint, filled from the model, decouples the API from the table, and is the way to rename or hide one model's fields only. `encoding/json` drops a key that two embedded structs at the same depth both give, so a model that embeds `ant.Base` beside another struct with a field tagged `json:"id"` encodes neither. A field the model declares itself wins over the embedded one.

A document stored before the upgrade, such as an `ant.JSON[Note]` snapshot, keeps its old keys in the column. Reading it still works, but a [containment or path condition](/models/custom-types#query-inside-json-postgresql) with the new keys misses it: see [JSON written before v0.6.0](/models/custom-types#json-keys-before-v060).

## Table and column names

| Go | Database |
| --- | --- |
| `type OrderItem` | table `order_items` |
| `UserID` | column `user_id` |
| `HTTPPort` | column `http_port` |
| `ID` | primary key `id` |

Table names are plural. ant adds `s`, or `es` after `s`, `x`, `ch` and `sh`, and turns a consonant followed by `y` into `ies`. That gives `categories` for `Category`, and also `persons` for `Person` and `childs` for `Child`. Set `b.Table` when the result reads wrong.

## Rename a column or a table

A tag renames a column. `Configure` renames a table.

```go
type Device struct {
	ID   int64
	// spot-next-line
	Name string `ant:"column=display_name"`
}

func (Device) Configure(b *ant.ModelBuilder[Device]) {
	// spot-next-line
	b.Table("hardware")
}
```

## Leave a field out

A field tagged `ant:"-"` and any unexported field is not a column. ant never reads, writes or queries it.

```go
type Session struct {
	ID     int64
	Token  string
	// spot-start
	Cached string `ant:"-"`
	secret string
	// spot-end
}
```

## Change the naming rules

`ant.WithNaming` replaces the conventions for every model. A nil function keeps the default for that part. A name set explicitly is kept.

```go
db, err := ant.Open[AppDB](ctx, postgres.Dialect, dsn,
	// spot-start
	ant.WithNaming(ant.Naming{
		Table:  func(name string) string { return "tbl_" + name },
		Column: func(name string) string { return "col_" + name },
	}),
	// spot-end
)
```

`ant.WithConvention` runs a rule on every model as it is configured. A model's `Configure` method runs after the rule and can override it.

```go
rule := func(m *ant.ModelConvention) {
	for _, f := range m.Fields() {
		if f.Type.Kind() == reflect.String {
			// spot-next-line
			f.SetLength(100)
		}
	}
}

db, err := ant.Open[AppDB](ctx, postgres.Dialect, dsn, ant.WithConvention(rule))
```

:::warning[Set once per process]

Naming and conventions are global: ant reflects each model once per process, so they come from the first `Open`.

:::

The migrate program builds the schema from the same models, so give it the same options in `migrate.Config.Options`, or `diff` writes tables and columns under the default names:

```go
config := migrate.Config{
	// spot-next-line
	Options: []ant.Option{ant.WithNaming(naming)},
}
```

## What Open refuses

`ant.Open` reads every model, and every model its relations reach, and refuses one it would misread, with an error that names the field. It reports every broken model at once.

| Model | Error |
| --- | --- |
| An unknown or misspelled tag key, such as `ant:"uniqe"` | `ant.ErrBadSchema`: `unknown tag key "uniqe"`, and the keys ant has |
| A GORM tag, such as `ant:"primaryKey"` or `ant:"size:100"` | `ant.ErrBadSchema`, with the ant spelling: a field named `ID` is the key, `b.Column(&...Name).Length(100)` in `Configure` |
| A tag key in the wrong case, such as `readOnly` | `ant.ErrBadSchema`: write `readonly` |
| A value on a key that takes none (`unique=false`), or none on one that needs it (`column=`) | `ant.ErrBadSchema` |
| `prefix=` without `embedded` | `ant.ErrBadSchema` |
| Two fields on one column, such as `UserID` and `UserId`, or two embedded structs that both have `Name` | `ant.ErrBadSchema`, naming both fields |
| A relation slice of pointers, `[]*Post`, where `[]Post` is meant | `ant.ErrBadSchema` |
| A struct embedded by pointer, `*Base` | `ant.ErrBadSchema`: embed the value |
| A func, chan or `unsafe.Pointer` field | `ant.ErrBadSchema`: tag it `ant:"-"` |
| A relation whose foreign key can't be found | `ant.ErrNoForeignKey`, naming the fields it looked for and the `ForeignKey` call that names one |
| A slice, map, array or plain struct field with no `driver.Valuer` and `sql.Scanner`, on MySQL, MariaDB, SQLite or SQL Server, whose drivers can't take it | `ant.ErrNoColumnType`, naming each such field: store it with [`ant.JSON[T]`](/models/custom-types#json) |
| A table declared as a pointer, `*ant.Table[User]` | `ant.ErrBadSchema`: declare it as `ant.Table[User]` |

```go
_, err := ant.Open[AppDB](ctx, postgres.Dialect, dsn)
// ant: invalid schema: Typo.Email: unknown tag key "uniqe"; ant's tag keys are ...
```

A struct field with no tag and no exported fields of its own, such as `netip.Addr`, is a value the driver converts, not an embedded struct. On PostgreSQL a `netip.Addr` is an `inet` column that allows `NULL`, since pgx writes the zero `netip.Addr` as `NULL`.

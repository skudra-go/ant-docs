A model usually has a table to itself. These are the cases where it doesn't.

## Several models in one table

Go has no inheritance, so each type is its own plain struct, and a discriminator column says which rows belong to which. Insert sets the discriminator for you, and each model's queries see only its own rows.

```go
type Dog struct {
	ID    int64
	Kind  string
	Name  string
	Barks *int
}

func (Dog) Configure(b *ant.ModelBuilder[Dog]) {
	// spot-start
	b.Table("animals")
	b.Discriminator(&DG.Kind, "dog")
	// spot-end
}

type Cat struct {
	ID    int64
	Kind  string
	Name  string
	Lives *int
}

func (Cat) Configure(b *ant.ModelBuilder[Cat]) {
	// spot-start
	b.Table("animals")
	b.Discriminator(&CT.Kind, "cat")
	// spot-end
}

var (
	DG = ant.Fields[Dog]()
	CT = ant.Fields[Cat]()
)
```

```go
err := db.Dogs.Insert(ctx, &Dog{Name: "Rex"})
// INSERT INTO "animals" ("kind", "name") VALUES ($1, $2) RETURNING "id" -- $1 = dog

dogs, err := db.Dogs.Where(ant.Eq(&DG.Name, "Rex")).All(ctx)
// SELECT ... FROM "animals" WHERE "animals"."name" = $1 AND "animals"."kind" = $2 -- $2 = dog

cats, err := db.Cats.Where(ant.Eq(&CT.Name, "Rex")).All(ctx)
// SELECT ... FROM "animals" WHERE "animals"."name" = $1 AND "animals"."kind" = $2 -- $2 = cat
```

Migrations see one table. A column that only one model declares, such as `barks`, allows `NULL`.

## Split one table into several models

Models can share a table with no discriminator. This is table splitting: a small model for the common read, and a full one for the rest.

```go
type UserName struct {
	ID   int64
	Name string
}

func (UserName) Configure(b *ant.ModelBuilder[UserName]) {
	// spot-next-line
	b.Table("users")
}
```

To keep a separate table per type, embed a shared struct in each model. That is plain Go.

## Map a model to a view

`b.View` maps a model to a database view. It reads like a table and refuses every write with `ant.ErrReadOnly`. Create the view itself in [`migrations/code`](/migrations/hand-written#views-and-functions).

```go
type ActiveUser struct {
	ID   int64
	Name string
}

func (ActiveUser) Configure(b *ant.ModelBuilder[ActiveUser]) {
	// spot-next-line
	b.View("active_users")
}
```

A tracked row from a view can't be saved either: `SaveChanges` returns `ant.ErrReadOnly`.

## Put a table in a schema

`b.Schema` places a table in a database schema. Migrations create the schema and qualify every name.

```go
func (Invoice) Configure(b *ant.ModelBuilder[Invoice]) {
	// spot-next-line
	b.Schema("billing")
}
```

```go
invoices, err := db.Invoices.All(ctx)
// SELECT ... FROM "billing"."invoices"
```

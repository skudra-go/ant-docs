title: Validation
description: Check entities before they are inserted or updated.
---

Validation runs before every insert and update, and a failure stops the write. It runs at the same point as [hooks](/lifecycle/hooks-and-observers), so bulk writes skip it, and so does `ant.WithoutHooks`.

## Add a rule to a field

`b.Validate` attaches a rule to one field. The rule is typed to the field, and the `validate` package has the common ones.

```go
type Signup struct {
	ID    int64
	Name  string
	Email string
	Age   int
}

func (Signup) Configure(b *ant.ModelBuilder[Signup]) {
	// spot-start
	b.Validate(&S.Name, validate.All(validate.Required[string](), validate.MaxLength(50)))
	b.Validate(&S.Email, validate.Email)
	b.Validate(&S.Age, validate.Range(0, 150))
	// spot-end
}

var S = ant.Fields[Signup]()
```

| Rule | Checks |
| --- | --- |
| `validate.Required[V]()` | Not the zero value |
| `validate.Email` | A valid address |
| `validate.MinLength(n)`, `validate.MaxLength(n)` | String length |
| `validate.Range(low, high)` | Between two values, both included |
| `validate.OneOf(a, b, c)` | One of these |
| `validate.Matches(pattern)` | Matches a `*regexp.Regexp` |
| `validate.All(rules...)` | All of them |

A rule is a `func(V) error`, so a rule of your own is a plain function:

```go
func noSpaces(s string) error {
	if strings.Contains(s, " ") {
		return errors.New("must not contain spaces")
	}

	return nil
}
```

## Check rules that span fields

For a rule that reads several fields, give the model a `Validate` method. It runs on insert and on update.

```go
// spot-start
func (s *Signup) Validate(ctx context.Context) error {
	if s.Age < 18 && s.Email == "" {
		return errors.New("minors need a parent's email")
	}

	return nil
}
// spot-end
```

## Read the error

A failed field rule comes back as an `*ant.ValidationError` that names the model and field. The rule's own error is inside it, so `errors.Is` works with `validate.ErrRequired` and your own errors.

```go
err := db.Signups.Insert(ctx, &Signup{Email: "a@example.com"})

// spot-start
var invalid *ant.ValidationError

if errors.As(err, &invalid) {
	fmt.Println(invalid.Model, invalid.Field, invalid.Err) // Signup Name is required
}
// spot-end
```

## Return validation errors to an API client

Turn a `ValidationError` into a 422 that names the field, and let any other error through as a server error:

```go
func create(w http.ResponseWriter, r *http.Request) {
	signup := &Signup{Name: r.FormValue("name"), Email: r.FormValue("email")}

	err := db.Signups.Insert(r.Context(), signup)

	var invalid *ant.ValidationError

	switch {
	case errors.As(err, &invalid):
		http.Error(w, invalid.Field+": "+invalid.Err.Error(), http.StatusUnprocessableEntity)
	case ant.IsUniqueViolation(err):
		http.Error(w, "that email is already registered", http.StatusConflict)
	case err != nil:
		http.Error(w, "internal error", http.StatusInternalServerError)
	}
}
```

Rules run inside the write, so they cannot replace a database constraint. A rule can pass while another request inserts the same value, and the unique constraint is what catches it.

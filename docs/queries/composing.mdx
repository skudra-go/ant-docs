---
title: Composing queries
description: Reuse queries, add to them conditionally, and name them.
---

Builder methods always return a new query, so one query can be the starting point for others, and a function can hand back part of one.

## Reuse a query

```go
adults := db.Users.Where(ant.Gt(&U.Age, 18)).OrderBy(&U.Name)

alice, err := adults.Where(ant.Eq(&U.Name, "Alice")).All(ctx)
// SELECT ... FROM "users" WHERE "users"."age" > $1 AND "users"."name" = $2 ORDER BY "users"."name"

carol, err := adults.Where(ant.Eq(&U.Name, "Carol")).All(ctx)

// adults is unchanged, and can run again.
everyone, err := adults.All(ctx)
// SELECT ... FROM "users" WHERE "users"."age" > $1 ORDER BY "users"."name"
```

## Add parts only when needed

`When` adds to a query only if a condition holds at run time, so a search form doesn't need a chain of `if`s.

```go
func search(ctx context.Context, name string, adultsOnly bool) ([]*User, error) {
	return db.Users.
		OrderBy(&U.Name).
		When(name != "", func(q *ant.Query[User]) *ant.Query[User] {
			return q.Where(ant.Eq(&U.Name, name))
		}).
		When(adultsOnly, func(q *ant.Query[User]) *ant.Query[User] {
			return q.Where(ant.Gte(&U.Age, 18))
		}).
		All(ctx)
}
```

With no name and `adultsOnly` false, the query has no conditions. With both set, it has both:

```go
users, err := search(ctx, "Bob", true)
// SELECT ... FROM "users" WHERE "users"."name" = $1 AND "users"."age" >= $2 ORDER BY "users"."name"
```

## Name a reusable piece with a scope

A scope is a function that takes a query and returns one. Pass any number to `Scope`.

```go
func Adults(q *ant.Query[User]) *ant.Query[User] {
	return q.Where(ant.Gte(&U.Age, 18))
}

func OlderFirst(q *ant.Query[User]) *ant.Query[User] {
	return q.OrderByDesc(&U.Age)
}

users, err := db.Users.Scope(Adults, OlderFirst).All(ctx)
// SELECT ... FROM "users" WHERE "users"."age" >= $1 ORDER BY "users"."age" DESC
```

For a scope with parameters, write a function that returns one:

```go
func OlderThan(age int) func(*ant.Query[User]) *ant.Query[User] {
	return func(q *ant.Query[User]) *ant.Query[User] {
		return q.Where(ant.Gt(&U.Age, age))
	}
}

users, err := db.Users.Scope(OlderThan(30)).All(ctx)
// SELECT ... FROM "users" WHERE "users"."age" > $1
```

You apply scopes by hand. For a condition that should apply to every query of a model, use a [global filter](/lifecycle/global-filters) instead.

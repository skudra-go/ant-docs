## Overview

Columns are field pointers, not strings. `ant.Gt(&U.Age, 18)` is checked by the compiler, column and value both, and renaming a field updates every query that uses it.

```go title="main.go"
type User struct {
	ant.Base // ID, CreatedAt, UpdatedAt
	Name     string
	Age      int
	Posts    []Post // 1:N through Post.UserID
}

type Post struct {
	ant.Base
	UserID int64
	Title  string
}

type AppDB struct {
	ant.Context
	Users ant.Table[User]
	Posts ant.Table[Post]
}

var U = ant.Fields[User]()

db, err := ant.Open[AppDB](ctx, postgres.Dialect, dsn)

// spot-start
adults, err := db.Users.
	Where(ant.Gt(&U.Age, 18)). // ant.Gt(&U.Age, "18") won't compile
	Include(&U.Posts).         // one query for all the posts
	All(ctx)
// SELECT ... FROM "users" WHERE "users"."age" > $1
// SELECT ... FROM "posts" WHERE "posts"."user_id" IN ($1, $2, ...)

adults[0].Age++

err = db.SaveChanges(ctx)
// UPDATE "users" SET "age" = $1, "updated_at" = $2 WHERE "users"."id" = $3
// spot-end
```

## Install

```bash
go get github.com/skudra-go/ant
go get github.com/jackc/pgx/v5/stdlib  # or the driver for your database
```

ant needs Go 1.27 or later, because it uses generic methods. It hasn't reached 1.0, so the API can still change between releases; each [release](https://github.com/skudra-go/ant/releases) lists its breaking changes.

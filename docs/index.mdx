## Overview

Columns are field pointers, not strings, so the compiler checks them. Renaming a field renames it in every query.

<CollapsibleCode title="models.go" note="User, Post, AppDB">

```go
type User struct {
	ant.Base // ID, CreatedAt, UpdatedAt
	Name     string
	Age      int
	Posts    []Post // 1:N through Post.UserID
}

type Post struct {
	ant.Base
	UserID int64
	Title  string
}

type AppDB struct {
	ant.Context
	Users ant.Table[User]
	Posts ant.Table[Post]
}
```

</CollapsibleCode>

```go title="main.go"
var Users = ant.Fields[User]() // the probe: &Users.Age names the age column

db, err := ant.Open[AppDB](ctx, postgres.Dialect, dsn)

// spot-start
adults, err := db.Users.
	Where(ant.Gt(&Users.Age, 18)). // ant.Gt(&Users.Age, "18") won't compile
	Include(&Users.Posts).         // one query for all the posts
	All(ctx)
// SELECT ... FROM "users" WHERE "users"."age" > $1
// SELECT ... FROM "posts" WHERE "posts"."user_id" IN ($1, $2, ...)

adults[0].Age++

err = db.SaveChanges(ctx)
// UPDATE "users" SET "age" = $1, "updated_at" = $2 WHERE "users"."id" = $3
// spot-end
```

```text title="go build, with &Users.Agee"
Users.Agee undefined (type *User has no field or method Agee)
```

## Install

```bash
go get github.com/skudra-go/ant
go get github.com/jackc/pgx/v5/stdlib  # or the driver for your database
```

ant needs Go 1.27 or later, because it uses generic methods. It is pre-1.0, so the API can still change; each [release](https://github.com/skudra-go/ant/releases) lists its breaking changes.

## Databases

|  | PostgreSQL | MySQL | MariaDB | SQLite | SQL Server |
| --- | :---: | :---: | :---: | :---: | :---: |
| Queries, writes, relations, tracking, transactions | ✓ | ✓ | ✓ | ✓ | ✓ |
| Migrations | ✓ |  |  |  |  |

PostgreSQL gets every feature first. [Databases](/reference/databases) lists the gaps and how ant handles them.

## Feedback

ant is pre-1.0, and the API is still open to change. If something reads awkwardly, is missing, or doesn't work with your database, [open an issue](https://github.com/skudra-go/ant/issues/new/choose). Questions and ideas go in [Discussions](https://github.com/skudra-go/ant/discussions).
